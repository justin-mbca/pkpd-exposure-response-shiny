# Data Dictionary and Provenance for SDTM and ADaM Files

This document describes the source, generation process, and key variables for each file in the `app/data_sdtm` and `app/data_adam` folders.

| File Name                | Source/Type | Generation Script/Process         | Description / Key Variables |
|------------------------- |-------------|-----------------------------------|-----------------------------|
| ae.csv                   | SDTM        | Provided as input                 | Adverse events; subject ID, event type, start/end date, severity, outcome |
| dm.csv                   | SDTM        | Provided as input                 | Demographics; subject ID, age, sex, race, treatment arm |
| ex.csv                   | SDTM        | Provided as input                 | Exposure; subject ID, dose, dosing date/time, amount |
| lb.csv                   | SDTM        | Provided as input                 | Lab results; subject ID, test name, value, units, date/time |
| pc.csv                   | SDTM        | Provided as input                 | Pharmacokinetics; subject ID, analyte, concentration, timepoint |
| dm_clean.csv             | ADaM        | R/data_cleaning.R                 | Cleaned demographics; filtered/standardized from dm.csv |
| ex_clean.csv             | ADaM        | R/data_cleaning.R                 | Cleaned exposure; filtered/standardized from ex.csv |
| lb_clean.csv             | ADaM        | R/data_cleaning.R                 | Cleaned labs; filtered/standardized from lb.csv |
| pc_clean.csv             | ADaM        | R/data_cleaning.R                 | Cleaned PK; filtered/standardized from pc.csv |
| exposure.csv             | ADaM        | R/derivations_exposure.R          | Derived exposure metrics (e.g., Cmax, AUC) per subject |
| exposure_full.csv        | ADaM        | R/derivations_exposure.R          | Full exposure dataset with all calculated metrics |
| cox_summary.csv          | ADaM        | R/tlf_generation.R                | Cox regression summary statistics for time-to-event analysis |
| logit_summary.csv        | ADaM        | R/tlf_generation.R                | Logistic regression summary statistics for binary outcomes |
| qc_missing_exposure.csv  | QC/ADaM     | R/quality_control.R or manual     | List of subjects with missing exposure data |
| qc_outliers.csv          | QC/ADaM     | R/quality_control.R or manual     | List of outlier values identified in data |

**Notes:**
- SDTM files are typically provided as raw input from the clinical database.
- ADaM files are derived/cleaned/analysis-ready datasets generated by the scripts in the R/ directory.
- QC files are for quality control and may be generated by scripts or manual review.
- For detailed variable definitions, see the corresponding script or the data standards documentation.
